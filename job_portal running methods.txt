Step 2:Alternative to curl (Using Postman)
If curl is problematic, use Postman to test the /api/login endpoint.

Install Postman:
Download and install Postman from www.postman.com/downloads/.
Create a Request:
Open Postman and create a new request.
Set the method to POST.
Set the URL to:
text

Copy
http://localhost:3000/api/login
Go to Headers and add:
Key: Content-Type, Value: application/json
Go to Body, select raw, choose JSON, and paste:
json

Copy
{
    "email": "admin@example.com",
    "password": "admin123",
    "userType": "admin"
}
Send the Request:
Click Send.
Share the response (e.g., {"error":"Server error"}).
